# S3 CLI Docs (Docusaurus 3)

## Quick start
```bash
cd website
npm install
npm run start
```

Build/preview:
```bash
npm run build
npm run serve
```

## Content
- Docs live in `website/docs/` (autogenerated sidebar)
- Announcements live in `website/announcements/`
- Static assets are in `website/static/` and served from site root (e.g. `/img/logo.svg`)

## Authoring
- Write pages in Markdown (`.md`) or MDX (`.mdx`)
- Use admonitions:
```md
:::tip
Helpful tip
:::
```
- Mermaid diagrams: fenced code blocks `mermaid`
- Draw.io diagrams: MDX only using raw-loader (see `website/docs/site/diagrams/drawio-guide.mdx`)

## Visual/theme
- Vercel-like minimalist theme with brand colors
- Light/dark modes

## OpenAPI (optional)
If you later want interactive API docs:
- Option 1: Link to a hosted Swagger UI with `?url=` pointing to your spec
- Option 2: Add an OpenAPI plugin (e.g., docusaurus-openapi-docs or Redocusaurus) and generate `docs/api/`

## Deploy via CLI
Use CI or run locally:
```bash
npm run build
python s3-cli.py deploy-snapshot \
  --folder-path ./website/build \
  --bucket <bucket> \
  --prefix /docs/s3-cli/ \
  --target-server AWS_S3
```
