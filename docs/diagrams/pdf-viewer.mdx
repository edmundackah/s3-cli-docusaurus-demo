# PDF Viewer

You can easily embed PDF documents into your Markdown pages using the `PdfViewer` component. This component provides a read-only view of the PDF inside a collapsible container.

## Usage

To use the `PdfViewer` component, import it at the top of your `.mdx` file:

```md
import PdfViewer from '@theme/PdfViewer';
```

Then, you can use the component in your Markdown, providing the filename of the PDF from the `/static/pdfs` directory:

```md
<PdfViewer url="simplepdf-test.pdf" />
```

### Custom Title

You can also specify a `title` for the collapsible section. The default value is `View PDF`.

```md
<PdfViewer url="simplepdf-test.pdf" title="View Test PDF" />
```

### Custom Dimensions

You can also specify the `width` and `height` of the PDF viewer by passing them as props. The default values are `width="100%"` and `height="800px"`.

```md
<PdfViewer url="simplepdf-test.pdf" width="800px" height="600px" />
```
