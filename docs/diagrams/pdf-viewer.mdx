# PDF Viewer

You can easily embed PDF documents into your Markdown pages using the `PdfViewer` component. This component provides a read-only view of the PDF, allowing users to view the document without leaving the page.

## Usage

To use the `PdfViewer` component, you'll need to import it at the top of your `.mdx` file:

```md
import PdfViewer from '@theme/PdfViewer';
```

Then, you can use the component in your Markdown, providing the URL of the PDF you want to display:

```md
<PdfViewer url="/pdfs/simplepdf-test.pdf" />
```

### Custom Dimensions

You can also specify the `width` and `height` of the PDF viewer by passing them as props. The default values are `width="100%"` and `height="800px"`.

```md
<PdfViewer url="/pdfs/simplepdf-test.pdf" width="800px" height="600px" />
```
