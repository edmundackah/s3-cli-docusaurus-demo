# Swagger/OpenAPI Viewer

You can embed Swagger/OpenAPI specifications into your Markdown pages using the `SwaggerViewer` component. This component renders a modern, interactive API documentation UI inside a collapsible container.

## Usage

To use the `SwaggerViewer` component, import it at the top of your `.mdx` file:

```md
import SwaggerViewer from '@theme/SwaggerViewer';
```

Then, you can use the component in your Markdown, providing the filename of the spec from the `/static/api` directory:

```md
<SwaggerViewer url="swagger.json" />
```

### Custom Title

You can also specify a `title` for the collapsible section. The default value is `View API Specification`.

```md
<SwaggerViewer url="swagger.json" title="Explore the Petstore API" />
```
