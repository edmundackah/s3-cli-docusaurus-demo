# Swagger/OpenAPI Viewer

You can embed Swagger/OpenAPI specifications into your Markdown pages using the `SwaggerViewer` component. This component renders an interactive API documentation UI.

## Usage

To use the `SwaggerViewer` component, you'll need to import it at the top of your `.mdx` file:

```md
import SwaggerViewer from '@theme/SwaggerViewer';
```

Then, you can use the component in your Markdown, providing the URL of the `json` or `yaml` spec file you want to display:

```md
<SwaggerViewer url="/api/swagger.json" />
```

### Custom Title

You can also specify a `title` for the collapsible section. The default value is `View API Specification`.

```md
<SwaggerViewer url="/api/swagger.json" title="Explore the Petstore API" />
```
