# Announcing the new S3 CLI documentation site

We’ve migrated our documentation to a new Docusaurus-based site with:

- Modern, responsive UI with dark mode
- Autogenerated sidebar from folder structure
- Local search across docs
- Clear authoring guides for Markdown/MDX, Mermaid, and Draw.io

## What changed for contributors
- Write docs under `website/docs/`
- Announcements live under `website/announcements/`
- See `website/README.md` for quick commands

## Links
- Docs: /docs/s3-cli/
- Announcements: /docs/s3-cli/announcements/

## How to contribute
- Create/edit Markdown/MDX pages
- Open a Merge Request using the provided template
- CI will run quality gates (Prettier, MDX lint, broken links, typecheck)

Thank you to everyone who helped migrate and review!
