# `_category_.json` parameters

Category files control how folders appear in the sidebar and in the generated index pages.
Place a `_category_.json` file in any folder under `website/docs`.

## Common fields
```json
{
  "label": "Commands",
  "position": 2,
  "collapsed": false,
  "link": { "type": "generated-index", "title": "CLI Commands", "slug": "/category/commands" }
}
```

- `label` (string): Sidebar label for the folder.
- `position` (number): Order among sibling categories (lower appears first).
- `collapsed` (boolean): Whether section is collapsed by default.
- `link` (object): Controls the category index page.
  - `type`: `generated-index` to auto-generate a landing page, or `doc` to point to a specific page.
  - `title` (string): Title for the generated index page (if `generated-index`).
  - `slug` (string): URL path for the index page (optional; defaults to `/category/<label-slug>`).

Using a specific doc as the index:
```json
{
  "label": "Configuration Management",
  "position": 4,
  "link": { "type": "doc", "id": "config-management/getting-started" }
}
```

## Optional navbar controls (custom)
We added optional `nav` fields, read by our config to build top-level navbar items for immediate subfolders of `docs/`.
```json
{
  "label": "Diagrams",
  "nav": {
    "label": "Diagrams & Code",
    "hidden": false
  }
}
```

- `nav.label` (string): Override the label used in the navbar for this category.
- `nav.hidden` (boolean): If `true`, do not add this folder to the navbar (still appears in sidebar).

## Notes
- If a folder has a `README.md`, Docusaurus uses it as the category index by default.
- Without `_category_.json`, folders still appear (autogenerated), with a default label based on folder name.
- Keep labels short and meaningful.
