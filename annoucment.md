### Announcing our docs migration: MkDocs ➜ Docusaurus

We’ve upgraded the documentation site to Docusaurus for a faster, more modern authoring and reading experience.

- **Platform**: Docusaurus 3.8.1 (Classic theme, dark-mode ready)
- **Search**: Local, client-side search with hashed index
- **Diagrams**: Built-in Mermaid + Draw.io plugin
- **Media viewers**: Collapsible PDF and Swagger viewers
- **UX**: Image zoom, code copy buttons, improved typography
- **Structure**: Clear docs/blog separation, autogenerated top navbar from categories

### What changed

- **New site location**: `website/`
  - **Docs**: `website/docs/` (served from `/docs/s3-cli/`)
  - **Announcements**: `website/announcements/` (served from `/docs/s3-cli/announcements/`)
  - **Static assets**: `website/static/` (served at site root)
- **Config**: `website/docusaurus.config.ts` (replaces MkDocs `mkdocs.yml`)
- **Sidebars**: `website/sidebars.ts` (replaces MkDocs `nav`)
- **Extras**: `@easyops-cn/docusaurus-search-local`, `docusaurus-plugin-drawio`, `docusaurus-plugin-image-zoom`

### Authoring highlights

- **Admonitions**: use Docusaurus `:::` blocks (note/tip/warning/danger/info/important/example)
- **Collapsible details**: use `<details><summary>...</summary>...</details>`
- **Mermaid**: fenced code blocks with `mermaid`
- **Draw.io**: `.drawio.svg` files render inline
- **PDFs**: place in `website/static/pdfs` and embed with `PdfViewer`
- **Swagger**: place OpenAPI in `website/static/api` and embed with `SwaggerViewer`

### Migration guide and script

- See `website/docs/site/mkdocs-migration.mdx` for mapping and gotchas
- Helper script: `website/scripts/migrate-from-mkdocs.py`
  - Copies common assets and translates common admonitions/details

### Run locally

```bash
cd website
npm install
npm run start
```

### Build for production

```bash
cd website
npm run build
npm run serve
```

### Notable defaults

- `baseUrl`: `/docs/s3-cli/`
- `trailingSlash`: `false`
- Dark mode enabled and respects OS preference
